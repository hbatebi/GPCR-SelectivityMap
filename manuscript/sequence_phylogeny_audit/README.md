# Sequence-interface and phylogeny audit source data

This directory contains the compact, publication-relevant outputs from the full Fritz audit. Large checkpoint files and bootstrap-level predictions are excluded from GitHub and should be deposited in the associated archival record.

Key conclusion: sequence and interface models lose their apparent advantage under stringent homology removal and are matched by global sequence similarity. Interface positions do not outperform non-interface positions at 30% identity. Endpoint geometry transfers better than sequence at intermediate identity thresholds, while neither representation establishes reliable transfer at the strictest threshold.

Interpretation must remain `no evidence of transfer`, not proof of biological absence, because stringent clustering can yield few valid folds and wide confidence intervals.
