# GPCR SelectivityMap v0.3.1

This is the first public manuscript-aligned GitHub release of GPCR SelectivityMap.

## Scientific position

GPCR endpoint structures are treated as composite observables that can integrate conserved activation geometry, evolutionary organization, receptor-side compatibility, ligand and experimental context, and partner-conditioned stabilization. The software tests which contributions remain supported as validation becomes progressively more stringent.

The package does not output calibrated functional G-protein coupling probabilities.

## Included

- static receptor profiling from experimental structures;
- receptor-grouped benchmarking and sequence-identity cluster transfer;
- global identity, taxonomy, missingness, and metadata baselines;
- physically predefined interface models and matched controls;
- label-provenance and receptor-only entity audits;
- contact-network, surface, approximate electrostatic, and elastic-network features;
- compact manuscript source data and editable SVG figures;
- exact project-specific manuscript workflow overlays;
- tests on Python 3.10, 3.11, and 3.12 through GitHub Actions.

## Claim boundary

Experimental interface-complementarity and receptor-compatibility commands are retained for transparent exploration. They are not validated functional coupling predictors and are not used as the basis of the manuscript's central conclusions.
