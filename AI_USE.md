# Use of generative artificial intelligence

Generative AI tools, including ChatGPT by OpenAI, were used during preparation of this software release and the associated manuscript for:

- prose editing and documentation restructuring;
- code assistance, code review, and consistency checks;
- cross-checking numerical values against exported source tables;
- development and refinement of plotting code and figure layouts;
- review of release metadata and public-repository organization.

All numerical results shown in the repository derive from the analysis code and archived source tables. AI tools were not used to fabricate data, replace scientific computation, or independently determine the manuscript conclusions. The GPCR molecular illustration used in the main figure was supplied by the author; plot values and uncertainty intervals were regenerated from the deposited source data.

The author designed the analyses, executed or supervised all computations, inspected the source outputs, reviewed the code and figures, and takes full responsibility for the scientific content and the public release.
