# Nature Communications v5 manuscript source-data archive

**Release candidate for repository archiving, 5 November 2026. Author approval pending.**

This directory contains the **29 source-data ZIP files** from the integrated Nature Communications v5 ligand-analysis candidate. Source Data 1–28 have been carried over unchanged from the manuscript v5 candidate; Source Data 29 is the exploratory ligand-contact case-study archive with the 15 PDB/mmCIF structures, reproducibility scripts, receptor-side contact calculations, matched Gα-interface comparisons, contact-cutoff and construct sensitivity, and qualified experimental efficacy annotations. `Supplementary_Figure_12.tif` is the case-study figure.

The exact original per-file names (including `_v2` suffixes where present) have been preserved. Their SHA-256 hashes and sizes are recorded in `../../docs/NATCOMMS_V5_SOURCE_DATA_MANIFEST.tsv`.

**Do not interpret this collection as an accepted paper, final author-approved journal deposit, evidence of a universal ligand-efficacy mechanism, or an independent demonstration of endpoint equivalence.** The five Warren et al. 2024 5-HT1A structures provide only four construct-category-matched *pairwise comparisons*, not independent biological replicates. Only three of the five ligands have verified numerical Gi1 Emax values in this release.

The earlier *provisional* archive-wide ligand/endpoint statistics package also used the label Source Data 29. **This release uses Source Data 29 exclusively for the final five-ligand/four-receptor atomic study.** The provisional dataset must not be deposited under the same source-data number.

The source code is also available in inspectable form under `../../manuscript_workflow/ligand_interface_v5/`; the complete underlying inputs remain in `Source_Data_29.zip`.
